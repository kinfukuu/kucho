# 句帳（初版）

## 内容
- iPhone Safari向けPWA
- IndexedDBによる端末内保存
- 作品の登録・編集・削除
- 五十音順／季節別／年別の並べ替え
- キーワード検索
- 変更前の句を推敲履歴として保存
- JSONバックアップ／復元
- 過去の会話で確認できた6句を初期データとして同梱（初期データJSONから取り込み）

## iPhoneで使うために
PWAをホーム画面に追加するには、HTTPSで公開されたWebサイトが必要です。ZIPをHTTPS対応の静的ホスティング（例：GitHub Pages等）に配置し、そのURLをiPhoneのSafariで開いて「共有」→「ホーム画面に追加」を選びます。
ローカルのHTMLファイルをSafariで開くだけでは、オフライン対応やホーム画面アプリ化が完全には動作しません。

## 初期データ
`starter-poems.json` をアプリ内「設定」→「バックアップから復元」で読み込むと、サンプル6句が登録されます。復元は現在のデータを置き換えるので、既存データがある場合は先にバックアップしてください。

## 注意
データは端末内ブラウザに保存されます。ブラウザデータ削除・アプリ削除などで失われる可能性があるため、定期的にJSONバックアップを保存してください。
